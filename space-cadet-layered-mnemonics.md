# Space Cadet layered mnemonics

The layered Kinesis variants expose Space Cadet functions on the `fun` layer.
Hold `End` or `PgDn` to enter `fun`.

## Explicit mnemonic placements

- `Quote` on `q` — Emacs `quoted-insert` / quote mnemonic.
- `Macro` on `e` — Emacs keyboard macro mnemonic.
- `Over Strike` on `t` — `T` depicts a strike over a beam.
- `Abort` on `g` — Emacs quit/abort reference (`C-g`).
- `Break` on `c` — terminal interrupt reference (`C-c`).
- `Hold Output` on `z` — terminal job/control-flow reference (`C-z`).
- `Clear Input` on `k` — Emacs kill-line reference.
- `Clear Screen` on `l` — terminal/Emacs clear/redraw reference (`C-l`).
- `Resume` on `m` — continue/resume mnemonic.
- `Status` on `u` — status/update mnemonic.
- `End` on `;` — punctuation/end-of-statement mnemonic.
- `Repeat` on `.` — vi repeat-last-change reference (`.`).
- `Call` on `i` — interrupt/drop-to-listener mnemonic.

## Other placement rules

- Roman numerals keep their number-row sequence: `I`/`II`/`III`/`IV` on `1`/`2`/`3`/`4`.
- Thumb/finger keys stay on the right number row in order: finger-left, thumb-up, thumb-down, finger-right.
- Remaining Space Cadet functions currently follow the old chord-derived neighborhood unless explicitly moved above.
